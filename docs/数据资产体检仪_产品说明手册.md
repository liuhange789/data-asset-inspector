## 二、解决的核心问题

### 2.1 客户痛点

| 痛点 | 描述 | 本产品解决方案 |
|------|------|---------------|
| **合规风险高** | 数据中包含身份证、手机号等个人敏感信息，直接交易违反《个人信息保护法》《数据安全法》 | 自动识别4类敏感字段（身份证、手机号、银行卡、邮箱），按3级策略分级脱敏 |
| **数据质量差** | 原始数据存在重复、格式不统一、异常值等问题，影响交易定价 | 自动去重、格式标准化、异常值检测，输出质量评级（A/B/C/D） |
| **资产不透明** | 企业不清楚自己有哪些数据资产、价值几何 | 自动扫描目录，生成资产清单和价值评估报告（1~5星评级） |
| **交易无标准** | 数据产品缺乏说明书，买方无法评估价值，交易所不予受理 | 自动生成标准化《数据产品说明书》，含数据样例、合规声明、定价建议 |
| **处理效率低** | 人工脱敏、清洗耗时长、易出错，无法规模化 | 全流程自动化，5条数据约5秒完成，支持批量处理 |
| **规则不统一** | 不同部门使用不同脱敏标准，无法统一管理 | 所有规则集中存储于JSON配置文件，一处修改全局生效 |

## 三、功能模块

### 3.1 数据脱敏模块

**解决的问题：** 消除数据中的个人敏感信息，满足合规流通要求。

| 能力 | 说明 |
|------|------|
| 敏感字段识别 | 自动识别身份证号、手机号、银行卡号、电子邮箱4类敏感数据 |
| 分级脱敏策略 | **完全匿名化（FULL）**：身份证号 → `***` |
| | **部分假名化（PARTIAL）**：手机号 `13912345678` → `139***5678` |
| | **泛化处理（GENERALIZE）**：邮箱 → `<脱敏数据>` |
| 审计日志 | 每次脱敏操作记录时间、操作人、输入输出路径，可追溯 |
| 规则可配置 | 敏感字段类型、正则表达式、脱敏级别均通过配置文件定义，无需改代码 |

### 3.2 数据清洗模块

**解决的问题：** 提升数据质量，达到交易标准。

| 能力 | 说明 |
|------|------|
| 去重处理 | 自动识别并删除完全重复的记录行 |
| 格式标准化 | 统一空白字符、去除首尾空格、规范分隔符 |
| 异常值检测 | 检测内容过短行、NULL值行等异常数据并标记 |
| 质量评级 | 按缺失率和错误率评定A（优秀）/B（良好）/C（合格）/D（不合格）四级 |

### 3.3 数据盘点模块

**解决的问题：** 摸清数据家底，量化数据价值。

| 能力 | 说明 |
|------|------|
| 目录扫描 | 自动扫描指定目录下所有数据文件（CSV/JSON/TXT/XLSX） |
| 价值评估 | 基于文件名关键词匹配，给出1~5星价值评级和处理建议 |
| 资产清单 | 生成结构化资产清单表格，含文件名、大小、类型、价值评级、建议 |
| 识别高价值数据 | 识别"供应链""销售明细""交易流水"等高价值数据并标记优先交易 |

### 3.4 数据包装模块

**解决的问题：** 将处理后的数据打包为标准化数据产品。

| 能力 | 说明 |
|------|------|
| 数据样例提取 | 自动提取前5行数据作为产品样例展示 |
| 合规声明生成 | 自动生成合规声明（已完成脱敏、不含个人信息、来源合法等） |
| 定价建议 | 基于数据价值评级给出定价建议（高价/中高价/综合定价/低价/评估成本） |
| 产品说明书 | 自动生成完整《数据产品说明书》，含产品名称、版本、数据概览、样例、合规声明、定价建议 |

### 3.5 全流程编排模块

**解决的问题：** 一键执行完整流程，无需人工逐步操作。

- 自动编排：脱敏输出 → 清洗输入 → 盘点目录 → 包装数据，路径自动传递
- 失败处理：任一阶段失败时停止后续阶段，返回已完成报告和失败原因
- 汇总报告：整合四阶段报告为一份完整的数据资产化处理报告
