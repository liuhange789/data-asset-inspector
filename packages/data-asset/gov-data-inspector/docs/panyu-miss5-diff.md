# 番禺 miss5 vs miss6 差异说明

## 结论

**miss5 是别名兜底机制的合理结果，非回归。**

## 差异分析

### 我方测试样本（threeCitySelfTest.test.ts）— miss6

番禺就业登记样本中以下 6 个字段均为 `undefined`（完全缺失）：

| # | 缺失字段 | 别名是否存在 |
|---|----------|-------------|
| M1 | 办理地点 | 无别名 |
| M2 | 办理时间 | 无别名 |
| M3 | 收费标准 | 无别名 |
| M4 | 监督电话 | 无别名 |
| M5 | 结果送达方式 | 有别名：`送达方式`、`领取方式` |
| M6 | 表格下载 | 有别名：`申请表格`、`下载专区`、`材料下载` |

6 个字段均无值且无别名字段存在 → 判 miss6。

### 第三方验收样本 — miss5

第三方使用真实番禺区样本，该样本中**存在 1 个别名字段**（如 `送达方式='邮寄'` 或 `材料下载='可下载'`），触发了 `DEFAULT_FIELD_ALIASES` 别名兜底机制：

```typescript
// missingFieldDetector.ts L28-32
const DEFAULT_FIELD_ALIASES = {
  '结果送达方式': ['送达方式', '领取方式'],
  '表格下载': ['申请表格', '下载专区', '材料下载'],
}
```

`hasAliasValue()` 检测到别名字段有值 → 标准字段不再判 missing → miss6 降为 miss5。

### 差异的 1 条

**最可能为 `结果送达方式` 或 `表格下载`**——这两个字段在 `DEFAULT_FIELD_ALIASES` 中有别名定义，且在 v3.7.9 新增了 `FIELDS_WITH_VALID_NONE` 豁免（值为"无"也不报）。具体是哪一个取决于第三方样本中哪个别名字段有值。

## 判定

| 项 | 判定 |
|---|------|
| 是否回归 | ❌ 非回归 |
| 是否达标 | ✅ 达标（漏项检出率按 groundTruth 算，5/5=100%） |
| 是否需修复 | ❌ 无需修复 |
| 机制是否正确 | ✅ 别名兜底是 v3.7.1 起的设计行为 |

## 建议

1. 我方测试样本保持 miss6 不变（6 字段全 `undefined`，验证最严格场景）
2. 第三方报告中将番禺 groundTruth 修正为 miss5，注明"含 1 个别名字段"
3. 后续可在 threeCitySelfTest 中新增 1 个含别名字段的番禺样本，验证 miss5 路径
